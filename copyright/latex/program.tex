\section{后端智能合约}

\subsection{CustomToken.sol（自定义代币合约）}

\textbf{文件大小:} 约 0.6 KB
\textbf{功能说明:} 基于 ERC-20 标准的自定义代币（CT）合约，负责代币的铸造与销毁操作。该合约是宠物商店生态系统中的核心经济代币，可与 ETH 进行双向兑换。

\lstinputlisting[style=codestyleln, language=Solidity]{../../src/CustomToken.sol}

\textbf{文件路径:} src/CustomPet.sol
\textbf{文件大小:} 约 2.3 KB
\textbf{功能说明:} 基于 ERC-721 标准的宠物非同质化代币（NFT）合约，继承 ERC721URIStorage 和 ERC721Enumerable，实现宠物的铸造、销毁、所有权查询及元数据存储功能。

\lstinputlisting[style=codestyleln, language=Solidity]{../../src/CustomPet.sol}

\subsection{Exchange.sol（代币兑换合约）}
\textbf{文件路径:} src/Exchange.sol
\textbf{文件大小:} 约 1.8 KB
\textbf{功能说明:} 处理 ETH 与 CT 代币之间双向兑换的交易所合约，按照委员会设定的汇率 $k$ 进行兑换，支持动态调整汇率。

\lstinputlisting[style=codestyleln, language=Solidity]{../../src/Exchange.sol}

\subsection{Trade.sol（交易合约）}
\textbf{文件路径:} src/Trade.sol
\textbf{文件大小:} 约 3.7 KB
\textbf{功能说明:} 用户之间的宠物交易合约，支持指定买方、有效期和价格的交易创建，卖方存入宠物 NFT、买方支付 CT 完成交易，以及交易取消和过期处理逻辑。

\lstinputlisting[style=codestyleln, language=Solidity]{../../src/Trade.sol}

\subsection{TradeFactory.sol（交易工厂合约）}
\textbf{文件路径:} src/TradeFactory.sol
\textbf{文件大小:} 约 1.3 KB
\textbf{功能说明:} 交易工厂合约，负责创建和管理用户之间的交易实例，维护所有交易记录的地址列表。

\lstinputlisting[style=codestyleln, language=Solidity]{../../src/TradeFactory.sol}

\subsection{Viewer.sol（用户状态查询合约）}
\textbf{文件路径:} src/Viewer.sol
\textbf{文件大小:} 约 3.5 KB
\textbf{功能说明:} 用户状态查询合约，提供用户拥有的宠物 NFT 列表查询、用户作为卖方/买方的交易记录查询等功能，方便前端页面展示用户资产和交易状态。
